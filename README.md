# Tacos Safary - Restaurant Website

A responsive restaurant website built with vanilla HTML, CSS, and JavaScript.

## Live Site
[tacossafary.com](https://tacossafary.com)

## Features
- Responsive design for mobile and desktop
- Menu display
- Location and hours information
- Contact section

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Deployment
Self-hosted on a personal Ubuntu Server 24.04 home lab, served via Nginx and routed through a Cloudflare Tunnel for security and HTTPS.

## Local Development
Clone the repo and open `index.html` in your browser — no build tools required.
